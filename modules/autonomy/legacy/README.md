# 자율비행 레거시

지금은 쓰지 않지만 기록과 참고용으로 남겨 둔 자율비행 코드를 모아 둔다. 실행기와 다른 모듈은 이 폴더를 불러 쓰지 않는다.
여기 있는 코드는 유지보수·검증 대상이 아니며, 옮겨 온 시점의 상태 그대로다.

## 들어 있는 것

- [mona_bench](mona_bench/README_MONA.md): MoNA-Bench 기반 단안 카메라 장애물 회피(깊이 추정 → ORB-SLAM2 → Fast-Planner → PID,
  ROS 1 Noetic Docker). 2026-11-04 ~ 11-10 실험, 2026-11-11 레거시로 옮김.
  - 옮긴 이유: 실기 자율 전진 1회(장애물 없음) 외에 회피 비행 성공 기록이 없고, 비행 중 SLAM 거리 오차(+24~50%)가 풀리지 않았다.
    최종 목표(지도·출발점·목적지를 주면 장애물을 피해 이동)에서 MoNA가 맡는 것은 경로 위 지역 회피 한 층뿐이다.
  - 다시 쓰려면: `mona_bench/run.ps1 -Action Build`로 이미지를 빌드하고 `export_da2_onnx.py`로 깊이 모델을 변환한다
    (둘 다 저장소에 없다). 실행기 연결(드론이 붙으면 `run.ps1 -Action Live` 시작, `prepare-flight`의 모델·이미지 준비,
    종료 때 `mona-live` 컨테이너 정지)은 이 폴더로 옮길 때 `apps/launcher`에서 뺐다. 필요하면 git 이력에서 되살린다.
  - 드론 게이트웨이의 자율 연결(`/ws/autonomy`)은 MoNA 전용이 아니라 그대로 있다.
