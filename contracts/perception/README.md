# 탐지 계약

현재 공통 형식은 [사람 탐지 이벤트 1.0](PERSON_DETECTION_EVENT_V1.md)이며,
[JSON Schema](person_detection_event_v1.schema.json)와
[공개 합성 예시](samples/person_detection_event_v1/)를 함께 제공한다.

PoC 초기 형식은 [PoC 연결 초안 0.1.0](../POC_V0_1.md)에 남겨 둔다.

영상 입력·탐지/사진 이벤트·객체 위치의 합의 문서와 공개 가능한 예제를 둔다. 원본 촬영이나 얼굴 자료는 포함하지 않는다.

최초 구현 시 지원 버전·설치·실행·테스트·설정 이름과 입출력 계약 링크를 이 문서에 추가한다.
팀 작업 절차는 저장소 루트의 docs/team/START_HERE.md를 따른다.
