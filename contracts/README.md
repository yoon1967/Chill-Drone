# 파트 간 계약

`mapping/`, `perception/`, `api/`에 실제 합의한 명세와 작은 예제를 추가한다.
현재는 폴더 경계만 준비했으며 JSON Schema·OpenAPI·ROS 메시지 정의를 임의 확정하지 않았다.

각 계약에는 버전, 생산자/소비자, 필수/선택 필드·타입, 좌표·단위·시각 기준,
정상·누락·무효 예제, 호환성·오류 처리, 확인한 Jira 작업 링크를 기록한다.
실제 영상·개인정보·토큰을 예제에 넣지 않는다.

휴대폰 3D 복원에서는 임의 스케일과 실측 보정 후 미터를 구분하고 frame_id·원본 PTS·run_id·버전을 보존한다.
정답 pose와 추정 pose, 미제공·상실 상태를 같은 정상 데이터로 취급하지 않는다.
구체적인 필드·출력은 현재 Jira 계약 작업에서 결정한다.
