# 시연 시나리오

재난 상황 실내를 드론이 스스로 정찰하며 지도를 그리고, 사람을 찾아 사진을 보내고, 다 보면 출발점으로 돌아와 회수되는 모습을 보인다.
운용자는 관제 화면 하나로 지켜보고, 필요할 때만 "저기로 가 봐"를 찍는다.
기준은 통합 브랜치 `feat/final-integration`(2026-11-17). 켜는 법은 [포팅 매뉴얼](PORTING_MANUAL.md).

| | (가) 실기체 | (나) 실기체 없이 |
| --- | --- | --- |
| 켜기 | `scripts\start.cmd autonomy` | `scripts\start.cmd sim`, 기록 다시 보기 |
| 켜는 데 | 약 3분 | 약 3분 30초 |
| 비행 | 약 2–3분(어림 110–185초) | 자율 탐색 약 8분 |
| 보여 줄 것 | 교실 밖 출발 → 정찰 → 교실 문 → 들어가 둘러보기 → 출발점으로 돌아와 착륙 | 같은 관제 화면 기능(시뮬레이터 영상) |

## 1. 줄거리 (한 번에 말하기)

> 사람이 들어가기 위험한 건물 안에 작은 드론이 먼저 들어갑니다. 드론은 스스로 길을 고르며 지도를 그리고, 사람을 찾으면 사진과 자리를 보냅니다.
> 운용자는 밖에서 화면 하나로 지켜보다 필요할 때만 "저 교실로 가 봐"를 찍습니다. 길 찾기·문 지나기·둘러보기는 드론이 합니다.
> 다 보면 온 길로 돌아와 회수됩니다. 남은 지도 위에 구조대가 들어갈 길과 사람까지의 동선을 그립니다.

## 2. 사람과 역할

| 역할 | 하는 일 | 자리 |
| --- | --- | --- |
| 운용자 | 관제 화면 버튼만: 주변 확인·시작, 필요할 때 지도 찍기·[여기로 보내기], "출발" 찍기, [착륙]. 위험하면 바로 [착륙] | 노트북 앞 |
| 화면 설명자 | 말하기, 화면 가리키기 | 발표 화면 옆 |
| 안전 지켜보는 사람 | 드론을 눈으로 따라가며 계단·유리·사람 쪽으로 가면 운용자에게 바로 알린다 | 출발 자리 옆·뒤 2 m 밖 |
| (선택) 구조 대상 1명 | 교실 안, 문 지나는 선에서 1.5 m 넘게 옆에 가만히 앉는다 | 교실 안 |

- 이 모드에서는 자율 비행이 드론을 조종한다. **손 조종(WASD)은 없다**(Tello는 조종 프로그램 하나에만 답한다).
- 관제 화면의 버튼은 자율 비행 웹과 **같은 명령**이다. 같은 비행을 자율 비행 웹 `http://127.0.0.1:8080`에서도 볼 수 있다.

## 3. 무대 배치

| 곳 | 맞출 것 |
| --- | --- |
| 교실 | 문을 활짝 연다. 문 안쪽 1.5 m를 비운다(의자·가방). 교실 가운데에 둘레 1 m 빈 자리(제자리에서 돌며 둘러볼 곳). 문 바깥(복도 쪽) 1 m도 비운다 |
| 출발 자리 | 교실 밖 복도, 교실 문에서 3–5 m. 문을 정면으로 보지 않게(문이 앞쪽 비스듬히 ±60° 안). 둘레 2 m 안에 계단·유리문·유리벽 없음. 바닥에 테이프로 자리·방향 표시(돌아와 내릴 자리, 둘레 1 m 비움) |
| 다른 문 | 계단·화장실·다른 교실 문은 닫는다 |
| 관람객 | 출발 자리 옆·뒤 2 m 밖. 출발과 교실 문 사이 복도, 문 둘레 1 m, 출발점 둘레 1 m에는 아무도 없게. 오가지 않는다 |
| 재 둘 것 | 교실 문이 출발에서 앞 몇 m·왼쪽 몇 m인지. 2D 지도는 켠 자리가 원점이고 x 앞·y 왼쪽이다 |

- 드론 앞 1 m 안에 선 사람은 장애물이 된다. 출발점 둘레에 사람이 있으면 돌아와도 그 앞에 내린다.
- 의자·탁자가 모인 곳은 탐색 구역에서 빼거나 치운다(11/17 낮게 날다 닿아 뒤집힘).

## 4. 시연 전 점검

**전날·30분 전**

- 노트북 **충전기**를 꽂는다. 배터리면 GPU가 묶여 자율 비행 인식이 약 10배 느려진다(11/16).
- 드론 배터리 완충(90% 이상 권장), 프로펠러 가드, 프로펠러·모터 점검(뒤집히거나 부딪힌 적이 있으면 꼭).
- 모델·환경 준비 끝(드론 Wi-Fi에는 인터넷이 없다): `scripts\start.cmd prepare-flight`, WSL 자율 비행 환경.
- 폰 Tello 앱, 점검 화면(`check_server.py`), 다른 실행기를 끈다.
- 드론 없이 한 번 끝까지: `scripts\start.cmd autonomy --fake-tello`(날지 않음).
- 리허설 2–3번(아래 7절).

**바로 전**

1. 드론을 켜고 PC를 드론 Wi-Fi(`TELLO-…`/`RMTT-…`)에 연결한다.
2. `scripts\start.cmd autonomy`를 켠다(약 3분). Wi-Fi 이름으로 확장 키트를 정한다(`RMTT-…`면 전방 ToF 씀).
3. 화면 `http://127.0.0.1:8020/?preset=autonomy#/live`에서 확인한다.
   - 머리 "자율 비행 보기 · 연결됨", 모드 지상, 영상, 2D 지도의 "출발"이 드론 자리.
   - 발견 칸 "탐지 동작 중", 실행기 창 "지도 시작".
   - launch 뒤 YOLO 준비(약 20초) 전에는 시작이 잠겨 있는 게 정상이다.
4. 시작 칸의 **기수 값이 "멈춤"**이 될 때까지 기다린다(드론이 붙고 40–55초). 그 뒤 **1–2분 안에** 이륙한다.
   켠 직후에는 기수 값이 흘러 Tello가 이륙을 거절하고, 땅에서는 분당 약 10°C 오른다.

## 5. 진행 순서 (실기체)

시각은 이륙 요청부터의 어림이다.

| 때 | 장면 | 운용자 | 화면에서 가리킬 것 | 말할 거리 |
| --- | --- | --- | --- | --- |
| 이륙 전 | 소개 | 기수 값 "멈춤" 기다림 | 연결 카드(드론·영상·사람 탐지·지도·자율 비행 점), 영상 원본 ↔ AI 합성, 사람 윤곽 | "파트 넷(자율 비행·사람 탐지·지도·관제)이 한 화면에서 돈다" |
| 0:00 | 이륙 | 조종 줄 "이륙" → 주변 확인 체크 → "이륙"을 4초 안에 두 번. 약 9초 뒤 뜬다 | 이륙 전 확인 칸(기체 점검·기수 값·주변 확인) | "사람이 주변을 확인해야 뜬다" |
| 0:10–0:20 | 처음 둘러보기 | 지켜봄 | 모드 카드 임무 단계, 알림 띠 "지금 하는 일" | "먼저 제자리에서 돌며 주변을 본다" |
| 0:20–1:20 | 정찰 | 2D 지도에서 교실 쪽을 지켜봄 | 2D 지도 벽·높은 것 / 낮은 물체 / 높이 모름 색, 찾은 장애물 이름표, 지나온 길, 계획 경로 | "카메라 깊이와 센서로 비행 높이 지도를 그리며 안 가 본 곳을 고른다" |
| 언제든 | 사람 발견 | 알림의 확인 / 오탐 | 분홍 알림(사진·번호·신뢰도), 발견 칸, 2D 지도의 번호 네모(그때 드론 위치) | "사진과 자리가 같이 온다. 사람이 확인해 오탐을 거른다" |
| 0:50–2:00 | 교실 문 → 문 지나기 → 둘러보기 | 6절 규칙대로 필요할 때만 찍기 | 단계 "문 지나기", 3D 점군(지도 칸 "3D 점군", 점 색 = 높이: 바닥 청록 → 벽 위 주황, 천장은 뺌) | "문 앞에서 멈춰 정면을 보고 곧게 지난다. 안을 돌며 지도를 채운다" |
| 1:20–3:00 | 돌아오기·착륙 | 2D 지도의 "출발"을 찍어 [여기로 보내기] → "도착해 둘러보는 중"이면 [착륙] | 찍은 자리 답(버튼 옆 20초), 지나온 길이 출발점까지 | "다 보면 온 길로 돌아와 회수된다" |
| 착륙 뒤 | 결과 | 새 탭 "탐색 결과"(`#/review`), 2D 지도 "✎ 그리기"(B) | 비행 시간·발견·지도·비행 기록, 진입로 → 사람 동선("사람 2 · 4.2 m · 약 9초" 꼴) | "구조대가 들어갈 길과 걸을 길을 지도 위에" |
| 끝 | 끄기 | 드론 끄기 → 실행기 창 Enter 두 번(드론이 꺼져 땅인지 모르므로 10초 안에 한 번 더) | | |

- 운용자가 놓쳐도 탐색 시간(자율 비행 기본 120초)이 다 되면 드론이 스스로 출발점으로 돌아와 내린다(`return_home` 기본 켬).
  탐색 시간은 처음 둘러보기를 마치고 첫 볼 자리를 고를 때부터 세고, 돌아오는 시간은 들지 않는다.
- 탐색 시간을 넉넉히 바꾸려면 자율 비행 파트 확인을 받는다(자율 비행 launch 인자 `search_time`).
  확인되면 실행기 뒤에 붙인다: `scripts\start.cmd autonomy search_time:=150`(실행기가 `real.launch.py`에 그대로 넘긴다).
- 지도 그리기는 드론 명령이 아니다. 동선은 드론 비행 높이 지도로 계산한 **추정**이라고 말한다.
  그리기를 켠 동안 Esc는 그리기 취소다. 비상 정지는 화면의 비상 정지 버튼(0.6초 길게)으로 한다.
- 착륙 뒤에도 2D 지도와 그리기는 남는다(가짜 자율 비행으로 확인, 11/17). 실기체에서는 리허설에서 한 번 더 본다.
  그리기를 켜면 넓은 지도 칸은 도구·동선 목록이 지도 옆으로 가고, 재난 정찰 화면은 지도 칸이 가장 큰 칸으로 바뀐다.

## 6. 언제 찍어 돕나

먼저 자율에 맡긴다. 찍기는 "교실로 가라"는 지시 한 번이고, 가는 길·피하기·문 지나기·둘러보기는 드론이 한다.
2D 지도를 한 번 클릭하면 보낼 자리가 찍히고, [여기로 보내기](G)로 보낸다. 탐색 비행 중에만 보낼 수 있다.

| 2D 지도에서 보이는 것 | 할 일 |
| --- | --- |
| 계획 경로 끝이 문 앞·교실 안, 단계 "문 지나기" | 찍지 않고 기다린다 |
| 교실 문 너머가 밝은 칸(본 빈 곳)인데 계획 경로가 다른 쪽(복도 끝·라운지)으로 간다 | 교실 안(문 너머 1.5–2 m 밝은 칸)을 찍어 보낸다 |
| 이륙 뒤 약 75초가 지나도 교실이 지도에 안 보인다 | 교실 문 쪽을 찍는다(어두운 칸이어도 된다). 그쪽을 본 뒤 교실 안이 밝아지면 교실 안을 다시 찍는다 |
| 답이 "옮긴 자리로 가서 찍은 쪽을 봅니다"이고 "도착해 둘러보는 중"이 된다 | 교실 안을 한 번 더 보낸다 |
| 탐색 시간이 다 돼 돌아가기 시작했는데 아직 교실 밖 | 교실이 가까우면 교실 안을 찍는다(다녀와 둘러본 뒤 스스로 돌아온다). 멀면 그대로 돌아오게 둔다 |

도왔을 때 설명:
> "교실이 지도에 나타나면 운용자가 '들어가 봐'를 지정하고, 길 찾기·문 통과·둘러보기는 드론이 스스로 합니다. 다 보면 온 길로 돌아와 회수합니다."

## 7. 리허설 (2–3번)

1. **1번째, 자율만:** 찍지 않는다. 스스로 교실에 들어가면 성공. 끝은 "출발" 찍기 → [착륙].
2. **2번째, 돕기 규칙:** 6절대로 찍는다. 끝은 같다.
3. **적어 둘 것:** 교실 문 너머가 지도에 처음 보인 때, 문 지나기 시작·끝(들어갈 때·나올 때), 돌아오는 데 걸린 시간,
   내린 자리와 출발점 사이 거리, 이륙·끝 온도와 배터리.
4. 1번째에 스스로 들어갔으면 본 시연은 "자율, 안 되면 돕기", 아니면 "돕기 규칙"으로 한다.

- 자율 비행은 한 번 끝나면 다시 시작하지 않는다. 다시 날리려면 실행기를 땅에서 끄고 다시 켠다(약 3분). 드론은 식히거나 배터리를 바꾼다.
- 11/17에 붙인 화면 기능(지금 하는 일 띠, 높이 띠, 뒤집힘 띠, 2D 벽·낮은 물체 칠하기, 지도 그리기, 3D 높이 색·천장 빼기)은 실기체에서 아직 확인하지 않았다. 리허설에서 처음 본다.

## 8. 안 될 때

| 상황 | 할 일 |
| --- | --- |
| 이륙 거절 알림 | 시작 대기로 돌아간다. 기수 값이 "멈춤"이 되면 다시 시작 |
| 계단·유리 쪽으로 간다 | 바로 [착륙](L) |
| 라운지·복도 끝으로 간다 | 6절대로 교실 안을 찍는다 |
| 답 "더 다가갈 수 있는 본 빈 곳이 없습니다" | 문 쪽의 밝은 칸을 찍는다. 그 자리에서 둘러본 뒤 교실 안을 다시 찍는다 |
| "옮긴 자리로 가서 찍은 쪽을 봅니다"만 되풀이 | 문이 닫혔거나 문 너머가 안 보인다. 문을 확인하고 [착륙] |
| "문 지나기를 그만둡니다" 1번 | 문 둘레 사람·의자를 치운다. 드론은 물러났다 다시 해 본다(찍은 자리였으면 다시 보낸다) |
| 같은 문에서 2번 그만둠 | [착륙] 후 처음부터 |
| 돌아오는 길에 가구 위로 오르거나 좁은 구석으로 간다 | 그 자리에서 [착륙] |
| 주황 띠 "자율 비행이 높이를 실제보다 … m 높게 보고 있습니다" / "드론 아래가 가깝습니다" | 바로 착륙을 생각한다. 띠의 [착륙] 또는 L |
| 온도 82°C 넘음 | 돌아오는 중이면 출발점 가까이까지 두고, 아니면 그 자리에서 [착륙]. 85°C면 자율 비행 드라이버가 그 자리에 내린다 |
| 출발점 앞에서 멈칫거림 | 출발점 둘레 사람을 비킨다. 2 m 안에서 30초 못 다가가면 스스로 그 자리에 내린다 |
| 빨간 띠 "드론이 뒤집혔습니다" 등 | 드론을 살핀다(프로펠러·가드·모터). 띠는 다음 이륙까지 남는다 |
| 벽·사람에 너무 가깝다 | [착륙]. 정말 위험할 때만 비상 정지(공중이면 떨어진다) |

## 9. (나) 실기체 없이

### 9-1. 자율 비행 시뮬레이터

```powershell
scripts\start.cmd sim
```

- 약 3분 30초 뒤 관제 화면 `http://127.0.0.1:8020/?preset=autonomy#/live`가 열린다. 같은 비행을 자율 비행 웹 8080에서도 본다.
- 시작은 실기체와 같다: 조종 줄 "이륙" → 주변 확인 체크 → "이륙"을 4초 안에 두 번. 2D 지도 클릭 → [여기로 보내기](G), 착륙 L.
- 자율 탐색 약 8분(11/15 이 PC: 임무 끝, 둘러본 넓이 69%). 사람 탐지가 시뮬레이터 사람을 찾아 분홍 알림·발견 지점을 보내고,
  3D 지도는 시뮬레이터 영상만으로 쌓인다(센서 자세 없음).
- 이 PC 시뮬레이터는 실시간보다 느리다(Tello 상태 약 4 Hz). 한 번 끝나면 다시 시작하지 않는다(다시 켠다).
- 끄기: 실행기 창 Enter.

### 9-2. 실기체 기록 다시 보기

```powershell
.\.venv\Scripts\python.exe -B modules\autonomy\tello_link\gateway_server.py --replay data\outputs\tello\<회차> --replay-loop
```

- 화면 `http://127.0.0.1:8010/#/live`. 위쪽에 "기록 재생"이 보이고, 명령은 모두 거절한다. `--replay-speed 2`(두 배속), `--replay-start 60`(60초부터).
- 자율 비행 보기 회차(`ros_…`)에는 영상 원본이 없다. 지나온 길·계획 경로·찾은 사람·발견 사진·3D 점·비행 기록을 다시 본다.
  2D 벽·장애물 칸은 다시 보기에 나오지 않는다(11/17 낮 전 회차에는 지도 파일이 없고, 그 뒤 회차도 마지막 판 `autonomy/grid.json`만 남는다).
- 이 PC 예: `ros_20261117_082502_d9f4bc`(11/17 08:25 실기체, 비행 135초, 둘러본 넓이 78 m², 사람 탐지 발견 11건, 자율 비행이 찾은 사람 9명).

### 9-3. 손 조종 (보여야 할 때만)

자율 비행과 같이 켤 수 없다. 자율 비행 실행기를 땅에서 끈 뒤 `scripts\start.cmd real` → 화면 `http://127.0.0.1:8010/#/live`에서
이륙 전 확인 → 이륙(T) → WASD 조종 → 착륙(L). 사람 탐지·3D 지도도 같이 켜진다.

## 10. 말할 때 조심할 것

- 교실에 스스로 들어간다는 **보장은 없다.** 볼 자리를 점수로 고르고, 문이 닫혀 있으면 교실은 후보가 안 된다. 그래서 6절의 돕기가 있다.
- "교실을 다 보면 바로 돌아오기"는 없다. 운용자가 "출발"을 찍어 돌려보낸다(놓쳐도 탐색 시간이 다 되면 돌아온다).
- 같은 사람이 여러 발견으로 잡힌다(같은 사람 묶기 없음). 자율 비행이 찾은 사람 수도 실제보다 많게 나온 적이 있다(11/16·11/17).
- 사람 동선은 드론 비행 높이 지도로 계산한 추정이다.
- 3D 지도는 카메라 한 대의 깊이 추정이라 크기·모양이 흐릿할 수 있다.
- 지난 실기체 귀환 9번 중 출발점에 내림 2번, 0.7–3.7 m 앞에 내림 4번, 운용자 착륙 2번, 충돌 1번이었다. "가까이 돌아와 회수"는 대체로 된다.
