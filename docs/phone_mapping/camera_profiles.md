# 카메라 보정 프로필

작업: https://ssafy.atlassian.net/browse/S15P31B205-349

기존 camera.json을 이 PC에 등록하고 실시간 지도 또는 영상·프레임 복원에서 재사용한다.
보정값을 계산하는 체크보드 튜토리얼은 다음 단계이며 이 기능은 이미 구한 값을 등록·선택한다.

## 등록과 내보내기

1. 실시간 지도에서 **보정 프로필 사용 → 프로필 관리**를 연다. 저장 지도 탭에서는 **카메라 보정 프로필**을 펼친다.
2. **보정 JSON 가져오기**를 눌러 보정 JSON 한 파일을 드롭하거나 선택한다. 64KB 이하이며 기존 width/height/fx/fy/cx/cy/distortion 형식을 사용한다.
3. 프로필 이름과 카메라·촬영 설정·사용 범위 요약을 확인한다. **상세 설정**에서 실제 기체·카메라 정보, 방향·크롭, 입력 경로를 변경한다.
4. 대상 확인란을 체크하고 **새 프로필로 저장**을 누른다.
5. 저장 후 위 **사용할 보정 프로필**에서 선택한다. **관리**에서 전체 목록·새로고침·내보내기를 사용한다.

내보낸 JSON도 같은 등록 화면에서 받는다. 저장소의 기존 Tello TELLO-59FA6D 실측값은 읽기 전용 기본 프로필로 제공한다.
가져온 파일의 품질 지표는 해당 파일에 기록된 정보로 표시하며 새로 정확도를 검증했다고 표시하지 않는다.
기존 파일을 덮어쓰지 않는다. 같은 입력의 재시도는 같은 항목을 반환하고 이름/대상이 다른 등록은 별도 ID를 만든다.
프로필 삭제·기존 프로필 수정은 제공하지 않는다. 새 이름으로 등록해 선택을 바꿀 수 있다.

등록 폼의 **사용할 입력 경로**는 기체 이름을 자동 인식한 값이 아니라 이 프로필을 선택할 수 있는 경로다.
**드론 영상 수신 + 파일 복원**, **브라우저 카메라 + 파일 복원**, **파일 복원만** 중 선택한다.
기본 화면에서는 현재 선택된 영상 입력에 대해 **이 입력의 기본 프로필로 기억**을 체크한다. 별도 입력 경로 선택 칸은 없다.
실제 기체·카메라 이름은 상세 설정의 식별 정보에 기록한다. 파일에 정보가 없으면 프로필 이름을 초기 식별값으로 사용하고,
방향·크롭은 가져온 파일 기준으로 표시한다. 이 값과 사용 범위를 요약에 보여 주며 확인란을 체크해야 저장한다.
드론 수신기는 현재 Tello 연결을 지원하며 이름 변경으로 다른 드론의 연결 기능이 추가되지는 않는다.
기존 저장 파일과의 호환을 위해 내부 입력 값 `tello`, `camera`, `file`은 유지한다.

## 적용 흐름

- 실시간 지도: 카메라 연결 → **3D 지도 생성 시작**. 보정은 선택 사항이며 사용 여부는 기본으로 꺼져 있다. 저장된 기본 프로필도 사용 여부를 켜기 전에는 적용하지 않는다.
- 실시간 보정 적용: **보정 프로필 사용**을 켜면 저장 프로필 선택과 JSON 업로드가 바로 표시된다. 별도의 카메라 일치 확인란 없이 선택한 값을 적용한다. 사용 여부를 끄면 이전 선택·업로드는 무시하고 기본값으로 시작한다. 다른 카메라로 연결하면 사용 여부는 다시 꺼진다.
- 실시간 JSON 업로드는 등록 없이 이번 실행에만 적용하며 프로필 선택과 동시에 사용하지 않는다. 선택한 파일은 형식과 해상도를 검사한다. 화각 입력은 프로필 관리의 상세 설정에서 제공한다.
- 영상·프레임: 자료 불러오기 → 위 카메라 보정 프로필 패널에서 복원용 프로필 선택 → 카메라·방향·크롭 확인 → 복원 시작.
- 선택한 프로필은 원본 입력과 가로·세로 크기가 정확히 같아야 한다. 다른 비율/크롭/회전으로 자동 변환하지 않는다.
- 브라우저 카메라는 프로필 크기로 장치를 요청하고, 전송용 단순 축소가 필요하면 기존 live_camera에서 내부 파라미터를 조절한다.
  프로필 자체의 원본 값은 변경하지 않는다. 파일 복원은 기존 OPENCV 고정 내부 파라미터 경로를 사용한다.
- 시작 요청에는 프로필 ID·버전·값의 SHA256과 명시적 확인을 전달한다. 서버가 프로필을 다시 조회해 실제 값을 적용한다.
  브라우저가 보낸 임의 camera 값으로 선택한 프로필을 덮어쓰지 않는다.
- 프로필을 선택하지 않거나 JSON 직접 선택을 사용하면 기존 입력 동작을 유지한다. 직접 JSON을 선택하면 프로필 선택은 해제된다.
  Tello의 기존 실측 기본값도 유지한다. 프로필 파일만으로 실제 기체를 자동 식별했다고 간주하지 않는다.

**이 입력의 기본 프로필로 기억**은 현재 선택한 입력 종류별로 저장한다. 해제하면 해당 입력의 기억만 지운다.
기본값 변경은 현재 선택을 바꾸지 않으며, 다른 입력 종류의 기본값도 바꾸지 않는다. 연결된 카메라용 프로필을 Tello에 적용하지 않는다.
저장 자료 복원은 기본 선택이어도 적용 전 대상 확인이 필요하다. 실시간 지도는 보정 사용 선택과 프로필 선택으로 적용 의사를 확인하며 별도의 확인란을 요구하지 않는다. 실시간 연결 준비·실행·정리 중에는 해당 프로필 선택을 잠근다.
등록과 기본 선택 변경은 실행 중인 지도나 과거 세션을 수정하지 않는다.

실시간 기본 화면에는 보정 사용 여부만 보이고, 사용 시 선택·업로드와 요약이 나타난다. 기본값 기억과 등록·내보내기는 프로필 관리에서 제공한다. 저장 자료 복원의 대상 확인은 유지한다.
수치·버전·파일의 품질 기록은 **보정값 상세 보기**로 접는다. **관리**의 프로필 선택은 정보 확인/내보내기 대상이며,
그 안의 **현재 입력에 선택**을 눌러야 실제 실행용 선택이 바뀐다. 입력 종류가 다르거나 수신 중이면 적용하지 않는다.
가져오기·관리를 닫아도 등록 중인 입력은 유지하고, 저장 성공 후에는 가져오기 폼을 닫는다. 저장만으로 실행 프로필을 바꾸지 않는다.

## 파일과 기록

```text
output/camera_profiles/
├─ defaults.json                   # 입력별 다음 기본 선택
└─ profile_<id>/
   └─ camera.json                  # 기존 보정 숫자 + profile 메타데이터
```

서버/CMD 재실행 뒤에도 이 위치에서 목록과 기본 선택을 읽는다. 검증용 별도 저장소는 `--profiles-root`로 지정할 수 있다.
내보낸 JSON에는 `profile.schema_version=mapping-camera-profile/1.0`, ID·버전·이름·대상·원본 해상도·방향/크롭·입력 종류·출처·값 해시가 있다.
다른 이름으로 다시 등록하면 로컬 새 ID를 부여하고 가져온 프로필 출처를 남긴다. 기존 평면 보정 JSON도 받는다.

실시간 세션의 camera.json과 settings.json에는 프로필 메타데이터 및 축소 후 실제 적용값이 함께 들어간다.
파일 복원의 입력 manifest와 options에도 선택한 값·메타데이터가 기록된다. 저장 지도를 다시 볼 때 현재 기본값으로 교체하지 않는다.
숫자가 유한하지 않거나 해상도·주점·왜곡 4개가 잘못된 파일은 거부한다. 손상된 저장 프로필은 목록 경고로 표시한다.

## 로컬 API

| 경로 | 동작 |
| --- | --- |
| GET /api/camera-profiles | 목록·입력별 기본 선택·읽기 경고 |
| POST /api/camera-profiles | 검증 후 새 프로필 등록 |
| GET /api/camera-profiles/export?id=… | 기존 보정 JSON 호환 파일 내보내기 |
| POST /api/camera-profiles/default | 입력별 다음 기본 선택 저장 |

기존 Origin/Host 및 X-Mapping-Client 검사를 유지한다. 카메라 자료를 원격으로 업로드하지 않는다.
