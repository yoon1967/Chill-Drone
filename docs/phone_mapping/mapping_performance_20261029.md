# 실시간 매핑 후속 성능 검증 · 2026-10-29

작업: https://ssafy.atlassian.net/browse/S15P31B205-344

## 변경

- 지도 잠금 중 native 값만 복사하고 JSON 조립·파일 저장은 잠금 밖에서 수행한다.
- 지도 발행 간격은 1초, 웹 지도 조회 간격은 750ms다. 잠금이 사용 중이면 주기적 발행을 건너뛴다.
- 추적 미리보기 저장은 별도 스레드·최신 대기 1개로 제한한다. 추적 통계는 최근 300프레임으로 제한한다.
- 호스트는 변경된 native JSON만 다시 읽는다. 보정값·영상 크기·ORB 특징점 목표 수·기하 수락 조건은 바꾸지 않는다.
- 상태 조회 실패·화면 렌더링 오류로 정상 매핑을 종료하는 경로와, 다른 영상의 ended 이벤트가 드론을 종료하는 경로를 차단한다.
- 최초 종료 원인과 클라이언트 오류를 보존하고 추적 상실 시 전후 프레임·검출/지도점 후보 수를 남긴다.
- 검증한 Ubuntu 기반 이미지 digest를 고정한다. CMD의 기존 소스 해시 검증과 자동 빌드는 유지한다.

## 동일 입력 비교

로컬의 연속 촬영 동영상 앞 24초를 각 실행에 동일하게 전달했다.
960×540, 30fps, ORB 목표 1,800개, Docker 6 CPU·8GiB, 순차 재생이다.
이 영상에 대응하는 기존 SfM 내부 보정 추정값을 공통으로 사용했다. Tello 실측 비행 시험이 아니다.
기존·개선 실행 후 개선·기존 역순으로 반복했다. P95는 각 tracking.jsonl의 전체 721장으로 다시 계산했다.
각 실행은 별도 지도이며 SLAM의 비동기 최적화 결과가 같다고 가정하지 않는다.

| 비교 | 기존 추적 P95 | 개선 추적 P95 | 기존 최대 | 개선 최대 | 정상 추적 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 기존 → 개선 | 38.86ms | 29.47ms | 99.73ms | 50.14ms | 각각 687/721 |
| 개선 → 기존 | 43.10ms | 36.24ms | 106.61ms | 53.45ms | 각각 687/721 |

P95는 15.9~24.2%, 최대값은 약 50% 감소했다. 이 2회 비교를 장시간 실기체 성능 보장으로 해석하지 않는다.
최종 native 점/키프레임 수는 각각 기존 5,679/84·5,621/81, 개선 5,649/73·5,650/80이다.
점 개수·추적 비율만으로 지도 정확도가 같다는 결론을 내리지 않는다. 정답 좌표에 대한 비교는 하지 않았다.

## 라이브 전달 경로 검증

실제 LiveSession·Docker·미리보기·지도 변환 경로에 로컬 JPEG를 24fps로 55초 동안 입력했다.
중간에 1초 검은 화면을 넣고 녹화 구간을 반복했다. 물리 드론·Wi-Fi·비행 조작은 사용하지 않았다.

- 1,320장 수신, 1,285장 제출, 대기 교체 34장. 마지막 대기 1장은 명시적 종료 시 폐기된다.
- 마지막 처리 PTS 54.92초, 지도 revision 33, 처리·미리보기 오류 없음.
- 각 초의 관측에서 세션은 receiving을 유지했고 마지막 명시적 user_stop으로 종료됐다.
- 추적 상실 4회 진단, 검은 화면의 검출 특징점 0개 기록, 전후 이미지 참조 및 16장 용량 제한 확인.
- 기존 수치 안전 가드의 샘플 거부는 8회이며 프로세스 오류는 없었다.

## 회귀 검증

- Python 통합: 49개 통과. 종료 중복·원인 보존·진단 API 검증·지도 JSON 재사용 포함.
- 지도 기하·고정 자세 대응: 25개 통과.
- Node 화면·입력·점군 표시: 80개 통과. 45초 초과 상태 조회 오류와 화면 예외 중 자동 종료 방지 포함.
- 루트 Python: 26개 통과. 실행기 4개는 샌드박스 임시 폴더 권한 오류 후 정상 권한에서 재실행해 통과.
- C++ Sim3 수치 검사·최근 300프레임 통계 경계 검사 및 Docker 최종 빌드 통과.
- 협업 템플릿 검사 2개·git diff --check 통과.

전체 영상·프레임·로그·비교 JSON은 로컬 output/에만 보관한다.
실기체의 장시간 추적 상실 원인과 실제 Wi-Fi 장애 복구는 다음 현장 시험에서 확인해야 한다.
