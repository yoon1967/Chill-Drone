# 저장 자료 불러오기

작업: https://ssafy.atlassian.net/browse/S15P31B205-306

`scripts/start_3d_mapping.cmd`를 실행하고 저장 지도 탭의 **저장 자료 불러오기**를 펼친다.
파일/폴더를 놓거나 선택하고 검사 결과를 확인한다. 원본은 덮어쓰지 않는다.
이 PC의 저장 기록 목록에서 이미 저장된 회차를 선택하면 대용량 영상·프레임을 다시 복사하지 않는다.
브라우저의 폴더 선택은 절대 경로를 제공하지 않으므로 선택한 파일을 이 PC 서버의 새 import 폴더로 복사한다.

| 입력 | 처리 |
| --- | --- |
| 세션 ZIP | CRC·상대 경로 검사 후 별도 폴더에 풀고 저장 지도를 연다 |
| `session.json` 또는 `state.json`과 `revisions/`가 있는 폴더 | 마지막 유효 지도와 기존 시간 슬라이더를 연결한다 |
| `scene.json`, `status.json`이 있는 결과 폴더 | 기존 저장 지도 뷰어를 사용한다 |
| `reconstruction/`과 `input/frames/`가 있는 파이프라인 폴더 | 결과와 촬영 이미지를 상대 위치로 다시 연결한다 |
| MP4·MOV·AVI·MKV | 실제 디코딩 검사 후 해상도·프레임 정보를 확인하고 새 복원을 시작한다 |
| JPG·JPEG·PNG 폴더 | 파일명 숫자 순서·앞/뒤 파일·해상도·촬영 FPS를 확인하고 새 복원을 시작한다 |

단독 `session.json`, PLY, 임의 JSON은 전체 지도 세션 입력이 아니다.
세션을 옮길 때에는 최상위 폴더 전체 또는 ③에서 내려받은 ZIP을 사용한다.
ZIP은 하나의 세션/결과를 담아야 하며 최상위 포장 폴더는 허용한다. 여러 세션을 하나의 ZIP으로 넣지 않는다.
불완전한 세션이나 손상된 일부 revision은 경고하고 남아 있는 유효 지도를 연다.
이미지가 누락되어도 지도·경로는 표시한다. 지도 자체가 생성되지 않았다면 빈 지도와 남은 영상 정보를 구분한다.

## 저장 지도와 영상

불러온 지도는 **저장 지도** 탭에만 연결하며 실시간 입력·녹화를 교체하지 않는다.
기존 점군/홀로그램/키프레임과 지도 시간 슬라이더를 재사용한다. 서로 다른 map ID의 좌표는 합치지 않는다.
수신 구간이 여러 개면 녹화 구간을 선택한다. MP4는 브라우저에서 독립 재생하며 MKV는 내려받아 재생한다.
녹화 영상과 지도 슬라이더를 자동 동기화하지 않는다. H.264의 수신 시각은 원래 촬영 시각의 근사치다.

`local_assets.json`의 이전 PC 절대 경로는 사용하지 않고 선택한 묶음 내부의 `frames/`,
`input/frames/`, `images/` 등으로 다시 연결한다. 예전 결과가 외부 이미지 폴더를 참조했다면
그 이미지를 결과 폴더의 `images/`에 함께 넣거나 파이프라인 전체 폴더를 선택한다.
CMD에서 개별 revision을 선택하면 같은 세션의 frames와 이력을 연결하고 해당 버전부터 표시한다.

## 영상·프레임 새 복원

입력 확인 → 프레임 준비 → 기존 SIFT·매칭 → 기존 SfM → 미리보기 → 결과 검사 순서로 진행한다.
실제 단계를 표시하며 계산 진행률을 추정 백분율로 꾸미지 않는다. 실패·취소 시 원본과 생성된 진단을 보존한다.
새 출력은 `output/phone_mapping/import_<id>/reconstruction_<id>/`에 저장한다.

- 영상의 추출 FPS 기본값은 2다. 촬영 PTS를 사용하며 디코딩 오류·시각 누락은 기존 입력 검사가 처리한다.
- 프레임은 3~10,000장, 같은 해상도여야 한다. 촬영 시각을 추측하지 않고 파일명 숫자 순서와 사용자가 입력한 FPS로 시간축을 만든다.
- 선택한 보정 JSON은 회전 적용 후 입력과 가로·세로 크기가 정확히 같아야 한다. `fx/fy/cx/cy`와 왜곡 4개를 검증한다.
  공급된 값은 OPENCV 카메라 모델로 전달하고 SfM의 내부 파라미터 재최적화를 끈다.
- 보정 파일을 제공하지 않으면 기존 SIMPLE_RADIAL 자체 추정을 명시한다. 다른 카메라에 Tello 실측값을 자동 적용하지 않는다.
- 확인란을 체크한 뒤 **새 지도 복원 시작**을 누른다. 복원은 한 번에 하나만 실행하며 실시간 매핑 중에는 시작을 거부한다.
  **불러오기·복원 취소**는 해당 작업과 하위 프로세스만 종료한다.
- 복원이 끝나면 **저장 지도 열기**로 이동한다. 작업 종료와 전체 프레임 복원 성공은 별개이며 부분 복원을 표시한다.

파일 드롭도 위 확인 화면으로 통일했으며 별도의 복원 엔진은 추가하지 않았다.
기존 CMD/웹은 종료 후 재실행해야 최신 서버와 화면을 사용한다. 보정 프로필 관리·튜토리얼은 다음 단계다.

## 로컬 처리와 HTTP

업로드/압축 해제는 청크 단위로 쓰고 묶음당 64GiB·50,000개 항목 한도 및 남은 디스크 공간을 검사한다.
상대 경로 탈출·Windows 별칭·중복 파일·심볼릭 링크/정션은 거부한다. ZIP 자체와 해제된 자료의 저장 공간이 각각 필요하다.
유한하지 않은 JSON 숫자·지원하지 않는 지도 스키마를 거부한다. 원격 업로드·임의 파일 탐색 API는 없다.
완료된 import 기록은 서버 재시작 뒤 같은 로컬 데이터 루트에서 다시 열 수 있다. 외부 폴더는 다시 선택할 수 있다.

| 경로 | 용도 |
| --- | --- |
| `GET /api/import/library` | 이 PC의 저장 기록과 import 목록 |
| `POST /api/import/create` | 새 복사 공간 생성 |
| `POST /api/import/upload?id=…&path=…` | 한 파일을 스트리밍 저장 |
| `POST /api/import/inspect?id=…` | 비동기 입력 검사 |
| `POST /api/import/local` | 목록의 local_id로 기존 회차 검사 |
| `GET /api/import/status?id=…` | 진행·요약·경고 |
| `POST /api/import/start?id=…` | 확인한 옵션으로 기존 파이프라인 시작 |
| `POST /api/import/cancel?id=…` | 해당 작업 취소 |
| `GET /api/import/media?id=…&part=…` | 등록된 녹화 구간만 Range 스트리밍 |
| `/api/saved/…?asset=…` | 기존 저장 지도 응답에 해당 자료의 읽기 바인딩 |

POST는 기존 Origin/Host와 `X-Mapping-Client` 검사를 사용한다. 자료 선택은 요청의 asset ID로 격리하며
한 브라우저에서 자료를 바꿔도 다른 브라우저나 실시간 지도 원본을 바꾸지 않는다.
