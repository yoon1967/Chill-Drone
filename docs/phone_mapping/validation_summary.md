# 단일 영상 파이프라인 검증 기록

확인일: 2026-10-23. 제작자 Windows/Python 3.12.14 환경의 검사 기록이다.
실행 방법은 [단일 명령 안내](video_pipeline.md), 자료 사용 순서는 [팀원 안내](team_guide.md)를 따른다.
새 영상 한 개를 끝까지 처리할 수 있는 흐름을 확인했으며, 서로 다른 장소 두 곳의 성능 비교 실험은 아니다.

## 자동 검사

저장소 루트의 Python 환경에서 실행했다. TEMP/TMP는 쓰기 가능한 로컬 임시 폴더로 지정했다.

| 명령 | 결과 | 주요 검사 |
| --- | --- | --- |
| `python -B -m unittest discover -s modules/mapping/data/tests -v` | 43개 통과 | 기존 입력 호환, 영상/PTS/회전·축소, DB/CSV, 단계 순서·오류·중단·시간, 저장 결과/PNG |
| `python -B -m unittest discover -s modules/mapping/localization/tests -v` | 8개 통과 | 3D/카메라 변환, 기존 보정, 부분/실패 상태, 원본 보호, 로컬 HTTP 뷰어 |
| `python -B -m unittest discover -s tests -p test_workflow_policy.py -v` | 2개 통과 | Jira 연동 템플릿의 문자열/양식 |
| `node --check apps/console/app.js` | 통과 | 뷰어 JavaScript 문법 |
| `git diff --check` | 통과 | 변경 내용의 공백 오류 |

위 결과는 로컬 검사이며 원격 CI/배포 성공을 뜻하지 않는다.

## 실제 영상 실행

기존 iPhone 13의 2층 복도 영상 하나를 새 입력으로 처리했다. 별도 실측이나 수동 점 지정은 사용하지 않았다.
PyCOLMAP 4.2.1, NumPy 2.3.5, SciPy 1.17.0, Pillow 12.3.0, PyAV 19.0.2,
matplotlib 3.10.8 환경이다. 두 실행 모두 2fps/JPEG 95/CPU 4스레드/매칭 창 4/max_features 4000을 사용했다.

| 항목 | A: 원본 해상도 | B: 축소 재실행 |
| --- | --- | --- |
| 처리 해상도 | 1920×1080 | 960×540 |
| 선택/등록 프레임 | 56 / 45 | 56 / 45 |
| 선택 모델의 3D 점 | 6,509 | 3,143 |
| 평균 재투영 오차 | 0.531px | 0.438px |
| 전체 상태 / 단위 | partial / arbitrary | partial / arbitrary |
| 전체 벽시계 시간 | 3,023.938초 | 132.901초 |

두 실행 모두 11장이 선택 모델에 등록되지 않았다. 별도 native 모델도 보존하며 좌표를 합치지 않았다.
재투영 오차는 영상 관측과의 일치 정도이고 실제 공간 정확도나 치수 오차가 아니다.

**A는 정상 속도 기준으로 사용하지 않는다.** 복원 내보내기 구간에서 2,154.483초의 시간 이상치가 관찰됐고 원인을 확인하지 못했다.
이 시간을 임의로 빼거나 정상 처리 시간으로 환산하지 않았다. B는 해당 PC/설정의 단일 관찰값이다.
해상도가 다르고 시스템 부하도 통제하지 않았으므로 A/B를 같은 조건의 처리 속도 비교로 해석하지 않는다.
전체/단계 시간의 포함·제외 범위는 실행 안내의 시간 측정 절을 따른다.

## 재실행·이동·소비자 확인

- B는 저장소 밖의 작업 디렉터리에서 절대 CLI 경로로 실행했다.
- A의 180개 파일은 B 실행 전후 SHA-256이 모두 같았다.
- A 회차 폴더 전체를 다른 위치/이름으로 복사하고 상대 참조와 저장 파일을 다시 읽었다.
  이미지용 local_assets.json만 복사본의 실제 위치로 연결했다.
- JSON/PLY/CSV, native 희소 모델의 점/카메라, 단위/좌표 변환·해시를 대조했다.
- 이동한 사본에서 만든 overview/projections PNG는 원래 PNG와 바이트가 같았다.
- 로컬 브라우저에서 45/56·6,509점·부분 복원/임의 단위 표시, 점군/카메라 경로/원본 사진을 확인했다.
  슬라이더의 처음/마지막 PTS와 새로고침 후 저장 결과 유지도 확인했다.

실제 영상/프레임/DB/PNG/전체 로그와 개인 경로는 Git에 추가하지 않는다. 실행 회차는 로컬 output/에 보존했다.
Drive 공유는 별도 등록 절차이며, 이 검증 기록 자체가 새 결과의 Drive 업로드 완료를 의미하지 않는다.

## 아직 확인하지 않은 항목

- 새 장소/드론 영상의 실제 복원 품질, 모든 코덱·기기 입력 지원.
- 독립 팀원 환경의 설치부터 실행까지 재현.
- 실제 거리·방향·바닥·공간 정확도와 밀집 표면 복원.
- 원본 해상도 실행의 시간 이상치 원인과 통제된 반복 성능 측정.
- 이 기능 MR의 develop 실제 머지 및 원격 CI/배포 결과.

complete/partial은 파일 처리와 등록 범위를 나타낸다. 전체 공간을 정확하게 복원했다는 보장은 아니다.
