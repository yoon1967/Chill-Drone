# 원본 녹화·세션 저장 검증 · 2026-10-29

작업: https://ssafy.atlassian.net/browse/S15P31B205-345

## 저장 범위

실시간 매핑과 함께 Tello 수신 H.264를 비동기로 저장한다. 수신기 재연결은 별도 구간으로 남기며,
종료 후 재인코딩 없이 재생용 MP4를 만든다. 브라우저·게이트웨이는 서버 수신 JPEG와 MKV를 저장하고
장치 H.264 원본과 구분한다. session.json이 영상·보정값·지도 시계열·키프레임·진단을 연결한다.
완료된 세션은 웹에서 ZIP으로 내려받는다. 불러오기 UI·보정 프로필·튜토리얼은 이 작업에 포함하지 않는다.

수신 스레드는 파일을 쓰지 않으며 큐는 8MiB로 제한한다. 큐 초과는 이미 받은 연속된 앞부분을 보존하고,
쓰기 실패와 재생 파일 생성 실패는 지도 처리 오류와 구분한다. 입력 종료·매핑 종료가 모두 확인된 뒤 저장을 마친다.
메타데이터 쓰기가 실패해도 녹화 정리를 수행하고 살아 있는 서버의 진단 manifest를 내려받을 수 있다.

## 종단 검증

Windows 로컬, PyAV 19.0.2, 기존 SLAM 이미지에서 검증했다. 녹화한 연속 영상을 가짜 Tello의 H.264 송출기로
전달하고 실제 SDK·UDP 수신·JPEG 추출·Docker SLAM·지도 검증·웹 저장 경로를 사용했다.
영상에 맞는 기존 내부 보정 추정값을 960×720에 맞춰 사용했으며, 실제 드론 비행이나 실측 보정 정확도 검증이 아니다.

- 추적 준비 뒤 약 32초간 입력했으며 중간에 약 6초간 송출을 끊었다가 복구했다.
- 같은 세션에서 재연결 1회, 입력·추적 제출 각각 476장, 대기 교체 0장, 매핑/미리보기 오류 없음.
- 원본 11,829,542바이트를 2개 구간으로 저장했고 소켓 수신 바이트와 파일 크기가 일치했다.
- 두 H.264 원본의 SHA-256을 다시 계산해 manifest와 대조했다.
- 생성 MP4 두 개를 실제 디코딩해 각각 287장·271장, 960×720 해상도를 확인했다.
- 최종 지도 revision 26, 확정 점 3,899개·키프레임 62개를 보존했다.
- 세션 ZIP 47,493,315바이트를 내려받아 ZIP CRC·원본 영상·보정값·세션 정보·지도 파일 포함을 확인했다.

파일 크기·프레임 수·지도 점 수는 이 검증 회차의 결과이며 다른 입력의 품질이나 실제 공간 정확도를 보장하지 않는다.
원본 촬영 시각이 없는 H.264의 MP4 시각은 PC 패킷 수신 시각 근사치다.

## 회귀 검사

- Python 통합 60개: 59개 통과, Windows 심볼릭 링크 생성 권한이 없어 1개 생략.
- 녹화 검사에는 원본 바이트 일치·MP4 디코딩·재연결·큐 초과·디스크 쓰기 실패·B-frame 재생 실패 시 원본 보존·ZIP 세션 격리를 포함한다.
- 지도 메타데이터 쓰기 실패 시에도 녹화 정리가 호출되는 것을 확인했다.
- Python 루트 26개·지도 기하 25개·Node 화면/표시 84개 통과.
- 공용 수신기를 사용하는 기체 어댑터 38개·탐지 경로 8개 검사 통과.
- 실제 CMD가 최신 화면 파일을 no-store로 제공하고 기존 Tello 실측 보정값을 유지하는 것을 확인했다.
- 저장된 검증 세션 화면에서 녹화 완료·연결 구간 2개·세션 ZIP 링크와 지도 표시를 확인했다.

실제 영상·프레임·전체 로그·검증 ZIP·스크린샷은 로컬 output/에만 보관한다.
실물 드론에서 장시간 녹화·저장 장치 한계·실제 무선 장애 상황은 추가 현장 확인이 필요하다.
