# 데이터 관리

`samples/`에는 작은 합성·공개 허가 자료만 커밋한다. 예제마다 출처·라이선스·생성 방법과 기대 결과를 남긴다.
개인 촬영·얼굴·실내 구조·위치·식별 가능한 로그의 공개 가능 여부를 추측하지 않는다.

`raw/`, `processed/`, `outputs/`는 로컬 실행 때 만들며 Git에서 제외한다.
필요한 데이터는 비공개 저장소의 식별자·체크섬·버전·접근 절차로 전달하고 비밀 다운로드 URL을 문서에 넣지 않는다.
모델·영상·점군을 Git LFS에 넣어도 접근권한이나 재배포 권한이 생기지는 않는다.

현재 폴더는 데이터 자동 수집·업로드를 수행하지 않는다.
