# Tello 카메라 실측 설정

`camera.json`은 사용자가 기본 적용을 요청한 TELLO-59FA6D 기체의 960×720
원본 스트림 보정값이다. 2026-10-28 로컬 체크보드 실험에서 확정한 수치만
포함하며 사진·영상·전체 로그는 포함하지 않는다.

내부 교차점 10×7, 칸 간격 22mm, 126장으로 최종 추정했다. 100장 추정/
26장 검증의 검증 RMS는 0.586px이며 같은 촬영 회차 내 검증이다. 독립 재촬영,
SLAM 정확도, 지도 수평·실제 미터 단위를 보장하는 값은 아니다.

서버의 Tello 입력 기본값으로 읽는다. 다른 기체·렌즈·크롭은
`serve.py --tello-camera <해당 기체 JSON>` 또는 기존 화면의 JSON 선택으로
명시적으로 교체한다. 이 파일을 다른 실험 결과로 덮어쓰지 않는다.
