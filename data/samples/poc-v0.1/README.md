# PoC 0.1.0 합성 결과 묶음

[공통 연결 초안](../../../contracts/POC_V0_1.md)의 결과 소비자용 예제다.
외부 자료를 사용하지 않고 이 저장소 작업에서 직접 작성했다. 원본 촬영·실제 인물·실내 위치·가중치가 없다.
점 3개와 카메라 pose 2개를 손으로 만든 구조 확인용 데이터이며 실제 RGB 복원·정확도 검증 결과가 아니다.
input_kind/pose_source가 synthetic이고 source_sha256은 null이다. 영상 입력 예제로 사용하지 않는다.

- `result.json`: 회차·임의 축척·카메라 변환·점군 파일 메타데이터.
- `points.ply`: ASCII XYZ/RGB 3점. result의 sha256/bytes는 이 파일의 실제 값이다.
- 두 번째 카메라 중심은 `[1,0,0]`, world→camera 변환의 t는 `[-1,0,0]`이다.
- 단위는 arbitrary. 화면에 m 단위로 표시하지 않는다.

파일은 작게 읽어 화면/수신기를 병렬 개발하는 데 사용한다. API·뷰어 프로그램은 이 묶음에 포함하지 않는다.
저장소 라이선스가 선택되기 전에는 오픈소스 라이선스가 부여된 것으로 간주하지 않는다.
