# 실내 탐색 관제 화면

드론 감독·탐색 결과·현장 조작 화면이다. 팀원 작업물(사람 탐지, 지도, 자율 비행, 드론 상태)이
프로젝트 목적인 **실내 탐색·사람 탐지·3D 지도**에 맞게 한 화면에 모이도록 자리를 잡았다.

화면은 두 가지로 동작한다.

| 동작 | 여는 방법 | 상단 표시 | 버튼 |
| --- | --- | --- | --- |
| **실시간** | 드론 게이트웨이(`gateway_server.py`)가 내준 주소 | 가짜 Tello / 실기체 | `/ws/drone`으로 **실제 명령을 보낸다** |
| 샘플 | 정적 서버로 열거나 주소에 `?sample` | 샘플 데이터 | 보내지 않는다. 샘플 값은 실측이 아니다 |

지금 실시간으로 채워지는 칸은 상태 카드, 조종 줄, 영상, 상세 상태, 비행 기록, 발견 목록(사람 탐지)이다.
2D 지도는 자율 비행이 게이트웨이 `/ws/autonomy`로 보낸 위치·계획 경로·찾은 사람을 m 눈금으로 그린다(지나온 길은 화면이 위치를 모아 그림).
자율이 연결되지 않았으면 안내만 한다. 시험은 게이트웨이 `--fake` + `tello_link/fake_autonomy.py`.

사람 탐지(실시간): 탐지 프로그램이 게이트웨이 영상을 받아 결과를 `POST /api/detections`로 보내면 화면에 나온다
(형식 `contracts/perception/PERSON_DETECTION_EVENT_V1.md`, 흐름은 `modules/autonomy/tello_link/README.md`).
- 발견 목록: 사람이 보이는 동안을 발견 하나로 묶은 카드. 대표 사진(신뢰도 최고 장면, 누르면 크게), 처음 본 시각, 최대 인원, 장수.
  탐색 결과 화면에는 그때 드론 모드·높이도 적는다. 화면을 새로 열면 `GET /api/detections`로 그동안의 발견을 불러온다.
- 영상 위 윤곽선: 최근 탐지의 사람 윤곽선(`polygons_px`)과 신뢰도를 1초 동안 그리고 탐지 지연(ms)을 적는다. 탐지 결과는 실시간 영상보다 늦게 온다.
  영상 칸의 **사람 윤곽** 버튼으로 켜고 끈다(이 브라우저에 기억, AI 합성 영상은 윤곽이 들어 있어 잠김).
- 새 발견이면 "사람 발견" 알림을 10초 띄운다(드론은 멈추지 않는다). 발견 칸 머리에 탐지 동작 중·끊김·연결 전과 초당 처리 장수.
- 드론 없이 보기: `gateway_server.py --fake` → 화면에서 영상 켜기 → `fake_detector.py`(합성 사람).

## 실행

Windows에서는 `scripts/start.cmd`를 더블클릭해 1이나 2를 고른다([실행기 안내](../launcher/README.md)).
1 체험(`scripts\start.cmd fake`)은 가짜 드론 + 사람 탐지 + 가짜 지도, 2 실기체 관제(`scripts\start.cmd real`)는 게이트웨이 +
사람 탐지 + 3D 지도(자동 시작)를 모두 켠다. 끌 때는 실행기 창에서 Enter(실기체가 공중이면 끄지 않는다).
브라우저를 자동으로 열지 않으려면 `--no-browser`, 옵션 안내는 `--help`를 사용한다.

허병우 팀원의 별도 자율비행 웹 서버는 `.\.venv\Scripts\python.exe -B infra\autonomy-web\launcher.py docker`(Docker) 또는
`.\.venv\Scripts\python.exe -B infra\autonomy-web\launcher.py wsl`(WSL ROS 2)로 실행한다. 기본 주소는 `http://localhost:8080`이다.
팀원 브랜치의 웹 ROS 노드를 실행하며 비행 드라이버·미션은 별도로 시작한다.
설치·연결·옵션은 [실행기 안내](../../docs/autonomy/WEB_LAUNCHERS.md)를 따른다.

빌드 과정 없이 정적 파일만 쓴다. 저장소 루트에서:

```powershell
# 실시간: 가짜 Tello로 조작까지 (실제 Tello는 --fake 없이)
python modules/autonomy/tello_link/gateway_server.py --fake
# 브라우저: http://127.0.0.1:8010/

# 샘플: 화면 구성만 보기
python -m http.server 8791 --bind 127.0.0.1 --directory apps/controller
# 브라우저: http://127.0.0.1:8791/  (상단 "상황" 목록으로 자율 탐색·사람 발견·통신 약해짐 등을 바꿔 본다)
```

### 조작 (실시간)

지도와 함께 실행할 때는 `scripts/start.cmd` 2(실기체 관제)가 **지도 콘솔**을 함께 켜고, **영상 켜기**를 누르면 지도를 시작한다.
게이트웨이를 지도 통합 모드로 띄웠을 때는 **영상 켜기**와 **키보드 조종 활성화**를 순서대로 선택한다. 지도 안을 클릭하면 이동 입력이 해제된다.
조종 줄의 **키보드 조종 활성화**를 다시 누르면 입력을 재개할 수 있다.

| 하는 일 | PC 감독 화면 | 폰 현장 조작 |
| --- | --- | --- |
| 이륙 | 이륙 버튼 또는 T → **이륙 전 확인** 칸에서 주변 확인 체크 → 칸의 이륙 버튼 또는 T | 이륙 버튼 → 칸에서 주변 확인 체크 → 칸의 이륙 버튼 |
| 이동 | W/S 앞뒤, A/D 좌우, ↑/↓ 높이, ←/→ 회전 (누르는 동안만) | 오른쪽 조이스틱 좌우·앞뒤, 왼쪽 조이스틱 회전·상하 |
| 착륙 | 착륙 버튼 또는 L | 착륙 버튼 |
| 비상 정지(모터 즉시 정지) | 비행·이륙 중 조종 화면에 포커스가 있을 때 Esc, 또는 버튼 0.6초 길게 | 버튼 0.6초 길게 |
| 영상 켜기·끄기 | 영상 칸 오른쪽 위 버튼 | (없음. 이륙하면 자동으로 켜진다) |

- 손을 떼거나, 창을 벗어나거나, 게이트웨이 연결이 끊기면 조종 입력은 0이 되고 기체는 제자리에 멈춘다.
- 통합 실행에서는 영상이 끊기면 이동 입력을 해제한다. 이륙에는 같은 화면에서 30초 이내의 주변 확인(이륙 전 확인 칸에 남은 시간이 보인다)과
  정상 영상, 지상 확인, 유효한 상태, 배터리 20% 이상, 온도 75°C 미만이 필요하다.
- 통합 실행 중 상태가 1초 넘게 끊기거나 배터리가 15% 미만이거나 온도가 85°C 이상이면 착륙을 요청한다.
  `L`을 이륙 중에 누르면 이륙 응답 직후 착륙을 요청한다. Esc는 비행 중 모터를 정지시키므로 기체가 떨어질 수 있다.
- 이륙을 누르면 조종 줄 위(폰은 큰 버튼 위)에 **이륙 전 확인** 칸이 뜬다. 기체 점검(✓/✗/!), 필요하면 영상, 주변 확인 체크가 차례로 있고
  다 되어야 칸의 이륙 버튼이 눌린다. 필수 점검 항목의 ✗는 이륙을 막고 칸에 까닭이 나온다. 칸을 열 때마다 주변 확인을 새로 하고,
  취소하거나 창을 떠나면 확인을 푼다(게이트웨이 규칙은 그대로).
- 자율 시작은 PC 감독 화면에서만 할 수 있다. 자율 비행이 아직 연결되지 않아 지금은 잠겨 있다.
- 상태가 10Hz로 바뀌어도 바뀐 칸만 다시 그린다. 영상, 조이스틱, 길게 누르는 중인 비상 정지가 갱신 때문에 끊기지 않는다.
- 단독 조종에서는 온도 75°C 이상을 !로 표시한다. 통합 실행에서는 같은 온도에서 이륙을 막는다.
- 영상은 게이트웨이를 켜도 자동으로 켜지지 않는다. 지상에서 영상을 켜 두면 기체가 1분에 약 16°C 뜨거워지기 때문이다(10/28 실기체).
  이륙하면 자동으로 켜지고, 지상에서 30초 넘게 켜져 있으면 "발열 주의" 경고를 띄운다. 끄지는 않는다(지도·자율처럼 땅에서
  영상이 계속 필요한 시험이 있어서). `--no-video`로 띄우면 버튼이 잠긴다.

### 폰으로 열기

게이트웨이를 `--host 0.0.0.0`으로 띄우고, 관리자 PowerShell에서 같은 망에서만 8010을 연다(시험 뒤 규칙 삭제).

```powershell
New-NetFirewallRule -DisplayName "Drone gateway 8010 (test)" -Direction Inbound -Protocol TCP -LocalPort 8010 -RemoteAddress LocalSubnet -Action Allow
Remove-NetFirewallRule -DisplayName "Drone gateway 8010 (test)"   # 시험이 끝나면
```

PC는 드론 Wi-Fi, 폰은 USB 테더링으로 PC와 잇고 폰 브라우저에서 `http://<PC 테더링 주소>:8010/#/control`을 연다.
아직 인증이 없어 같은 망의 누구나 조작 화면에 들어올 수 있다.

### 실기체 확인 (2026-10-28, Tello EDU + 확장 키트, 폰 조작)

| 항목 | 결과 |
| --- | --- |
| 연결 | 폰(USB 테더링) → 게이트웨이(PC, 드론 Wi-Fi) → Tello. 폰 화면 "실기체" 표시, 조이스틱 축 값 지상 확인 |
| 이륙 → 착륙 | 주변 확인 → 이륙(응답 8.9초) → 약 42초 비행 → 착륙(응답 3.8초) |
| 조이스틱 | 사람 rc 480개, 네 축(앞뒤 214·좌우 61·상하 255·회전 255) 모두 사용, 최대 30. 손을 떼면 데드맨으로 0(24개) |
| rc 전송 | 평균 62ms(약 16Hz), 최대 66ms. 첫 수동 비행(10/23)과 같은 간격 |
| 높이 | 하방 tof 최고 1.20m일 때 `h`는 최고 0.40m. `h`를 믿기 어렵다는 허병우 10/27 관찰과 같다 |
| 온도 | 61 → 72°C (영상 끔) |
| **배터리** | **이륙 전 52 → 47%(2분), 이륙 뒤 2초마다 1%씩 줄어 착륙 후에도 같은 속도로 14%까지.** 지상에서도 같은 속도라 실제 소모보다는 배터리 상태(노후·충전 부족) 또는 기체의 잔량 추정 문제로 보인다. 다른 배터리·완충 상태로 다시 확인 필요 |

## 화면과 사용자

| 화면 | 주소 | 누가, 언제 | 가장 크게 보이는 것 |
| --- | --- | --- | --- |
| 실시간 감독 | `#/live` | 운용자, 비행 중 (PC) | 영상 + 탐지 상자, 발견 목록, 지도. 조종은 아래 한 줄 |
| 지도 콘솔 | `#/map` | 운용자, 지도 복원·편집 (PC) | **지도 복원**에서 촬영 영상이나 최근 복원을 열고, **지도 편집**에서 저장 점군을 수정한다. 비행 중 실시간 지도는 실시간 감독의 **3D 점군**에서 본다. |
| 탐색 결과 | `#/review` | 운용자·보고 담당, 임무 후 (PC) | 발견마다 확인·오탐, 지도 위 발견 지점, 3D 지도, 비행 기록 |
| 현장 조작 | `#/control` | 드론 옆 보조 인원 (폰) | 큰 버튼, 조이스틱, 비상 정지(길게). 자율 시작은 없음 |

정보 우선순위(실시간 감독): ① 안전·조종 주체(상단 상태 카드) ② 급한 알림(사람 발견, 통신 약함) ③ 무엇이 보이나·어디 있나(영상·발견·지도)
④ 개입(조종 줄) ⑤ 세부 수치(영상 아래 한 줄).

상태 카드는 모드·배터리·높이(하방)·발견·연결 5개다. **연결** 카드는 팀 파트(드론·영상·사람 탐지·지도·자율 비행)가 지금 붙어 있는지를
점(채운 점 = 정상·주의·끊김, 빈 점 = 연결 전·꺼짐)과 짧은 말로 보여 준다. 위 막대 오른쪽은 연결 표시(실기체·가짜 Tello·기록 재생 + 연결됨·연결 중·끊김)다.
조종 줄 오른쪽 끝은 늘 이륙/착륙과 비상 정지다. 자세한 기준은 [DESIGN.md](DESIGN.md) "공통 틀".

실시간 감독은 **모니터 한 화면에 스크롤 없이** 들어간다(가로 1100px·세로 700px 이상, 1366×768과 1920×1080에서 확인).
왼쪽은 영상, 오른쪽 위는 발견 목록, 오른쪽 아래는 지도이며 각 칸은 창 크기에 맞춰 줄어든다. 발견이 많으면 목록 안에서만 스크롤된다.
이보다 작은 창과 폰에서는 위에서 아래로 쌓이고 페이지가 스크롤된다.

### 화면 프리셋과 편집 (실시간 감독)

- 위 막대 **화면**에서 칸 배치를 고른다. 기본 프리셋은 `presets.js`(재난 정찰·자율 탐색·지도 만들기·기록 검토), 주소에 `?preset=<id>`를 붙이면 그 프리셋으로 연다.
- **편집**(땅에 있을 때, 가로 1100·세로 700 이상): 칸을 끌어 옮기고, 다른 칸 위에 놓으면 두 칸의 자리를 바꾸고, 오른쪽 아래 모서리로 크기를 바꾼다. 편집 막대에서 칸을 넣고 빼고, 칸의 "중요 ↑"로 중요한 순서(좁은 화면에서 쌓는 순서)를 바꾼다.
- 저장하면 **내 프리셋**으로 이 브라우저에만 남는다(기본 프리셋은 고치지 않는다). 편집 중에 이륙하거나 창이 좁아지면 편집을 닫는다(저장 안 함).
- 상태 카드·알림·조종 줄(착륙·비상 정지)은 칸이 아니라서 어떤 배치에서도 그대로 있다.

### 테마와 디자인 기준

- 위 막대 **테마**: 자동(이 기기의 밝게/어둡게 설정)·밝게·어둡게. 고른 값은 이 브라우저에만 남는다. 영상 칸은 두 테마 모두 어둡다.
- 색은 `style.css` 맨 위 토큰에서만 정한다(밝게 `:root`, 어둡게 `:root[data-theme=dark]`, `theme.js`가 고름). 뜻과 쓰는 규칙, 글꼴, 부품은 [DESIGN.md](DESIGN.md).
- `tests/test_controller_theme.py`가 쓰는 토큰이 다 있는지와 두 테마의 글자 대비(4.5:1 이상)를 본다.

| 탐지 윤곽선, 발견 목록 | WS `detection`, `GET /api/detections`, 사진 `/api/detections/<event_id>.jpg` | `person-detection-event/1.0` (`contracts/perception/`) | 사람 탐지 → 드론 게이트웨이 |
| 지도 경로, 현재 위치, 찾은 사람 | `drone_state.pose`, `GET /api/autonomy`의 `path`·`people` (map 좌표, m) | `contracts/api/AUTONOMY_BRIDGE_V0_1.md` 4장(초안, `people` 추가) | 자율 비행 |
| 3D 지도 | 점군·카메라 경로 | `contracts/mapping/VIEWER_SOURCES_V1.md` (`apps/console`) | 지도 |

- **발견 지점은 사람 위치가 아니다.** 탐지 시각에 가장 가까운 드론 위치를 찍는다(실시간은 위치 추정 연결 전이라 모드·높이만). POC 4장대로 `object_position`은 null이며
  2D 상자나 카메라 위치를 사람의 3D 위치로 쓰지 않는다.
- 3D 지도: 실시간 감독 지도 칸의 **3D 점군**은 지도 연결기(`tello_link/gateway_map_bridge.py`)가 게이트웨이로 보낸 점군(`GET /api/map`)이다.
  **지도 콘솔**(`#/map`)에서 촬영 영상을 선택하면 복원이 시작된다. 처리 단계와 결과는 영상 복원 화면에서 확인한다.
  원본 프레임을 순서대로 추적하고, 첫 카메라 자세로 지도 기준을 잡은 뒤 기본 초당 5프레임의 깊이를 지도에 반영한다. 추적과 예측이 어려우면 마지막으로 확인한 자세에 합친다.
  저장된 점군은 지도 콘솔의 **지도 편집** 탭에서 선택해 수정한다. [편집 화면 안내](../console/README.md#3d-점군-편집)를 참고한다.
  영상 복원은 지도 서버가 처리하므로 다른 화면이나 브라우저 탭에서도 계속된다. 다시 들어와 최근 복원에서 결과를 열 수 있다.
  실시간 지도는 실기체 실행기가 시작한다. 지도 서버가 127.0.0.1에 열려 있어 지도 콘솔은 해당 PC에서 사용한다.
- 지도 칸 상태: 지도 시작 중 → 지도 수신 중. 드론 영상이 끊기면 **영상 기다리는 중**(몇 초째인지, 곧 돌아오면 같은 지도로 이어짐),
  오래 끊겨 콘솔이 지도를 끝내면 **영상 끊겨 지도 끝남**, 콘솔에서 마무리하면 지도 마무리 중 → **지도 끝남**. 받은 점군은 끝난 뒤에도 그대로 보인다.
  연결기가 지도 콘솔의 영상 입력 상태(`input_state`·`input_age_s`)를 같이 보내 게이트웨이 `drone_state.map`에 실린다.
- 확인·오탐 표시는 지금 브라우저 메모리에만 있다. 저장 위치(회차 폴더 또는 백엔드 API)는 연결 단계에서 정한다.

## 동작 규칙

- 지금 받을 수 없는 버튼은 `drone_state.allowed`에 따라 흐리게 보이고, 누르면 이유만 알린다.
- 비상 정지는 0.6초 길게 눌러야 한다. 긴장한 상태에서 잘못 눌러 공중에서 모터가 멈추는 것을 막는다.
- 사람 발견 시 드론을 자동으로 멈추지 않는다. 알림 옆 "여기서 멈추기"로 운용자가 정한다(오탐마다 멈추면 탐색이 진행되지 않는다).
- 모르는 값은 "없음"으로 표시하고 지어내지 않는다.
