# 실내 탐색 관제 화면 (화면 구성 단계)

드론 감독·탐색 결과·현장 조작 화면이다. 팀원 작업물(사람 탐지, 지도, 자율 비행, 드론 상태)이
프로젝트 목적인 **실내 탐색·사람 탐지·3D 지도**에 맞게 한 화면에 모이도록 자리를 잡았다.

**지금은 화면 구성만 있다.** 서버에 연결하지 않고 계약 형식의 샘플(`sample.js`)을 그리며, 버튼은 명령을 보내지 않는다.
화면 상단에 항상 "샘플 데이터"가 보인다. 샘플 값은 실측이 아니다.

## 실행

빌드 과정 없이 정적 파일만 쓴다. 저장소 루트에서:

```powershell
python -m http.server 8791 --bind 127.0.0.1 --directory apps/controller
```

브라우저에서 `http://127.0.0.1:8791/`을 연다. 상단의 "상황" 목록으로 자율 탐색, 사람 발견, 통신 약해짐,
자율 응답 지연, 수동 비행, 이륙 전을 바꿔 볼 수 있다.

## 화면과 사용자

| 화면 | 주소 | 누가, 언제 | 가장 크게 보이는 것 |
| --- | --- | --- | --- |
| 실시간 감독 | `#/live` | 운용자, 비행 중 (PC) | 영상 + 탐지 상자, 발견 목록, 지도. 조종은 아래 한 줄 |
| 탐색 결과 | `#/review` | 운용자·보고 담당, 임무 후 (PC) | 발견마다 확인·오탐, 지도 위 발견 지점, 3D 지도, 비행 기록 |
| 현장 조작 | `#/control` | 드론 옆 보조 인원 (폰) | 큰 버튼, 조이스틱, 비상 정지(길게). 자율 시작은 없음 |

정보 우선순위(실시간 감독): ① 안전·조종 주체(상단 상태줄) ② 급한 알림(사람 발견, 통신 약함) ③ 무엇이 보이나·어디 있나(영상·발견·지도)
④ 개입(조종 줄) ⑤ 세부 수치(영상 아래 한 줄).

실시간 감독은 **모니터 한 화면에 스크롤 없이** 들어간다(가로 1100px·세로 700px 이상, 1366×768과 1920×1080에서 확인).
왼쪽은 영상, 오른쪽 위는 발견 목록, 오른쪽 아래는 지도이며 각 칸은 창 크기에 맞춰 줄어든다. 발견이 많으면 목록 안에서만 스크롤된다.
이보다 작은 창과 폰에서는 위에서 아래로 쌓이고 페이지가 스크롤된다.

## 칸별 데이터 출처

각 칸 제목 옆 점선 표시가 그 칸을 채울 작업물이다.

| 칸 | 들어올 데이터 | 형식 | 생산 |
| --- | --- | --- | --- |
| 상태줄, 조종 줄, 상세 상태 | `drone_state` | `contracts/api/DRONE_CONTROL_V0_1.md`(초안) | 드론 게이트웨이, 기체 제어 |
| 영상 | MJPEG `/video.mjpg` | 같은 문서 5장 | 드론 게이트웨이 |
| 탐지 상자, 발견 목록 | 탐지 이벤트 `events.jsonl` | `contracts/POC_V0_1.md` 4장 (`bbox_xyxy_px`, `confidence`, `pts_us`) | 사람 탐지 |
| 지도 경로, 현재 위치 | `pose`, `path` (map 좌표, m) | `contracts/api/AUTONOMY_BRIDGE_V0_1.md` 4장(초안) | 자율 비행 |
| 3D 지도 | 점군·카메라 경로 | `contracts/mapping/VIEWER_SOURCES_V1.md` (`apps/console`) | 지도 |

- **발견 지점은 사람 위치가 아니다.** 탐지 시각(`pts_us`)에 가장 가까운 드론 위치를 찍는다. POC 4장대로 `object_position`은 null이며
  2D 상자나 카메라 위치를 사람의 3D 위치로 쓰지 않는다.
- 3D 지도는 지금은 `apps/console`(기본 `http://127.0.0.1:8790/`)을 새 창으로 연다. 화면 안에 넣는 방식은 지도 쪽과 정한다.
- 확인·오탐 표시는 지금 브라우저 메모리에만 있다. 저장 위치(회차 폴더 또는 백엔드 API)는 연결 단계에서 정한다.

## 아직 계약에 없는 것 (화면 자리만)

| 항목 | 화면 | 다음 단계 |
| --- | --- | --- |
| 통신 품질 `link`(단계, 상태 Hz, 응답 ms, SNR) | 상태줄 "통신 좋음/약함", 통신 약함 알림 | 통신 품질 측정 작업에서 계약에 추가 |
| 비행 시간 `flight_time_s` | 상태줄, 탐색 결과 | 게이트웨이 상태에 추가 |
| 출발점 복귀 `return_home` | 점선 버튼(누르면 안내만) | 자율 비행 쪽과 되짚기 방식 합의 후 |
| 발견 사진 | 어두운 썸네일 자리 | 탐지 쪽 사진 저장 형식 합의 후 |

## 동작 규칙

- 지금 받을 수 없는 버튼은 `drone_state.allowed`에 따라 흐리게 보이고, 누르면 이유만 알린다.
- 비상 정지는 0.6초 길게 눌러야 한다. 긴장한 상태에서 잘못 눌러 공중에서 모터가 멈추는 것을 막는다.
- 사람 발견 시 드론을 자동으로 멈추지 않는다. 알림 옆 "여기서 멈추기"로 운용자가 정한다(오탐마다 멈추면 탐색이 진행되지 않는다).
- 모르는 값은 "없음"으로 표시하고 지어내지 않는다.
